NYC 311 Cloud Data Pipeline

Built a cloud-based data pipeline to store and query 200,000 NYC service requests using AWS. Uploaded raw CSV data to S3, queried it with SQL through Athena, and loaded results into SageMaker to prepare for predictive modeling.

AWS S3 AWS Athena AWS SageMaker SQL Python (Pandas, boto3)
More details

Problem

A dataset of 200,000 NYC 311 complaints is too large to work with comfortably on a laptop. The goal was to store the data in the cloud, query it efficiently without downloading it, and set up an environment ready for machine learning.

Approach

I created an S3 bucket to store the raw complaints and agency CSV files in an organized folder structure. I then used AWS Athena to run SQL queries directly against the S3 data — no database server required. Finally, I launched a SageMaker notebook instance, cloned my project repo into it, and loaded the query results into pandas for exploration and modeling prep.

Results & Impact

Successfully queried 200,000 rows of complaint data in seconds using SQL without any local processing. Identified patterns in complaint volume by agency and borough, and built a modeling-ready dataset exported back to S3. Documented the full workflow in a public GitHub repository.

SQL Analytic Story: Film Rental Trends

Conducted a stakeholder-focused analysis of the Sakila database using advanced SQL. Identified top-performing genres and customer behavior patterns to provide actionable business insights.

MySQL Docker Python (SQLAlchemy) Jupyter Notebooks Pandas
More details

Problem

Managing a massive film inventory requires understanding which genres drive the most revenue and which customer segments are most active. Without a structured analysis, store managers are left making inventory decisions based on intuition rather than data.

Approach

I used a Dockerized MySQL instance to query the Sakila dataset. My analysis involved joining multiple tables (category, film, rental, and payment) to calculate running totals and rank genres. I utilized Common Table Expressions (CTEs) to organize my queries.

Results & Impact

The analysis successfully identified the 'Sports' and 'Sci-Fi' genres as the highest revenue generators. I delivered a final report that visualized these trends, providing an idea for future inventory management and specific marketing strategies for high-value customers.
