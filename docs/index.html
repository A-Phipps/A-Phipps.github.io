Cloud Infrastructure: NYC 311 Pipeline

Developed a scalable data pipeline using AWS services. Configured S3 for data storage, setup Athena for serverless SQL queries, and used SageMaker for data exploration.

AWS S3 AWS Athena AWS SageMaker SQL Python (Pandas)
More details

Problem

Large-scale urban datasets like the NYC 311 service requests are too large for traditional local processing. The goal was to build a cloud-native infrastructure that allows for efficient storage, rapid querying, and machine learning readiness without taxing local hardware.

Approach

I established a 'Bronze/Silver' data lake pattern in S3, using specific prefixes to organize raw and cleaned data. I then mapped this data to AWS Athena to perform serverless SQL analysis. Finally, I connected a SageMaker Jupyter instance to the Athena lifecycle to prepare the data for predictive modeling.

Results & Impact

The resulting infrastructure allows for querying millions of rows in seconds using SQL. The project is fully documented in a public AWS Cloud Computing repository, meeting all requirements for professional cloud data engineering standards.

SQL Analytic Story: Film Rental Trends

Conducted a stakeholder-focused analysis of the Sakila database using advanced SQL. Identified top-performing genres and customer behavior patterns to provide actionable business insights.

MySQL Docker Python (SQLAlchemy) Jupyter Notebooks Pandas
More details

Problem

Managing a massive film inventory requires understanding which genres drive the most revenue and which customer segments are most active. Without a structured analysis, store managers are left making inventory decisions based on intuition rather than data.

Approach

I used a Dockerized MySQL instance to query the Sakila dataset. My analysis involved joining multiple tables (category, film, rental, and payment) to calculate running totals and rank genres. I utilized Common Table Expressions (CTEs) to organize complex logic and Window Functions to determine percentile rankings for customer lifetime value.

Results & Impact

The analysis successfully identified the 'Sports' and 'Sci-Fi' genres as the highest revenue generators. I delivered a final report that visualized these trends, providing a clear roadmap for future inventory procurement and targeted marketing campaigns for high-value customers.
